## 只叫了一个，怎么来了这么多？

本文承接上一篇：[《服务器一开口，页面爆仓了》](/websocket)。

执行大厅门口，长长的消息处理器还挂在门框上。

订单、库存、聊天、通知……几十种 `type` 挤在一个 `switch` 里，最后一段代码已经拖进咖啡机下面。

JavaScript 老大踩住纸卷，冲门口的小家伙招手。

“`import`！把处理订单的请来，其他人先别动。”

`import` 点点头，领进一只抱着订单簿的模块。

后面跟着统计员。

统计员后面跟着日志员。

日志员后面还跟着配置员。

JavaScript 老大数到第四只，咖啡停在半空。

“不是只叫了一个吗？”

订单模块举起工作单：“处理完订单，要更新计数。”

统计模块举起另一张：“更新计数，要记日志。”

日志模块从身后又拽出一只：“写到哪里，得先看配置。”

队伍仍在往里走。

`import` 回头看了一眼，满意地点头：“人缘不错。”

“这是上班，不是办酒！”

一名加载员推着登记台赶来，灰蓝色背心上别着一串地址卡。

加载员刚展开名册，纸卷便从桌边一路滚到地上。

“先别挤。谁找谁，全部画出来。”

## 房间先分好

JavaScript 老大拎起剪刀，准备把旧文件平均剪成四段。

加载员按住剪刀：“按长度分？”

“每段一百行。公平。”

“把函数从腰上剪断，也挺公平。”

剪刀收了回去。

管房间的小弟从变量大厅赶来，把订单处理、库存更新、消息分发各自领进一间房，再在门上装了小窗口。

“文件可以拆，谁能用里面的东西，也得说清楚。”

订单模块先交出一份代码：

```javascript
// orders.js
const prefix = "新订单";

export function handleOrder(message) {
    console.log(prefix, message.id);
}
```

消息分发模块在自己的工作单上写下：

```javascript
// main.js
import { handleOrder } from "./orders.js";

handleOrder({ id: 7049 });
```

`handleOrder` 的窗口亮了，`prefix` 还待在订单模块的房间里。

库存模块趴在窗外：“里面那个 `prefix`，借我一下。”

订单模块关上半扇窗：“没出口。”

“那我也叫 `prefix`，会不会撞名？”

“各住各的，撞什么？”

小弟把两张同名门牌分别挂进房间。

“模块有自己的作用域。顶层声明不会因为名字一样就挤进同一个公共抽屉，也不会自动挂到 `window` 上。要把绑定交给别的模块用，就明确 `export`；要接进来，就明确 `import`。”

JavaScript 老大摸了摸房门：“这下谁都进不来，挺安全。”

浏览器老大从窗口伸进一根手指，指向旁边的 `document`。

“只是在管名字。页面模块照样可能操作 DOM、调用全局 API。别把作用域当保险柜。”

小弟顺手在门背后贴好严格模式的规章，又划掉一张写着“顶层 `this` 就是 `window`”的旧纸条。

“模块自动使用严格模式，顶层 `this` 是 `undefined`。搬进来，就按新规矩办。”

## 名册怎么还会长？

房间分好了，JavaScript 老大准备开工。

加载员又把门挡住。

“订单模块还没备齐。”

“代码不都拿到了吗？”

“往上看。”

订单模块刚补好的工作单顶部，多了一行：

```javascript
// orders.js
import { increment } from "./counter.js";

export function handleOrder(message) {
    increment();
    console.log("新订单", message.id);
}
```

`counter.js` 又需要 `logger.js`，`logger.js` 还需要 `config.js`。

另一边，库存模块也递来一张申请：“我也找 `logger.js`。”

加载员在白幕上连线：

```text
main.js
├─ orders.js
│  └─ counter.js
│     └─ logger.js ── config.js
└─ stock.js
   └─ logger.js（同一个）
```

“这叫模块图。一个文件是一处节点，导入关系是一条边。两条线可以指向同一个模块，后面还可能绕回来。”

JavaScript 老大朝队伍挥手：“按进门顺序执行吧，谁先到谁先干。”

`logger.js` 立刻反对：“配置还没到，我往哪儿写？”

加载员把名册摊在桌上。

“静态 `import` 是事先声明的依赖。先读取模块、找出依赖，沿着依赖继续加载；再把导入名和导出名接好，这一步叫链接；关系接通后，才轮到求值，也就是执行模块代码。”

“所以先把订单模块跑起来，再跑到 `import` 那一行去找人？”

“顺序倒了。静态导入在模块代码执行前就要处理，不能拿它当普通函数调用。”

JavaScript 老大把一条 `import` 塞进 `if`，试图蒙混过关。

解析警报当场响起。

加载员把申请抽出来：“静态 `import` 声明放在模块顶层，来源写成字符串。想等条件成立再叫人，后面有另一套手续。”

队伍里的 URL 已经在抄地址。

订单模块塞来 `./counter.js`，URL 转身朝首页目录跑。

“回来！”加载员指着订单模块的门牌，“外部模块里的相对导入，以这个模块自己的 URL 为基准，不是永远以 HTML 地址为基准。”

另一张卡片只写着 `counter`。

URL 翻遍口袋：“这个往哪儿送？”

“裸名字要有地址映射。浏览器不会自己去 `node_modules` 翻包。这里先写清相对路径；需要别名，可以另配 `import map`。”

加载员在纸角补了一句：浏览器拿的是部署后的文件和依赖，打包工具若提前改过图，实际加载的就是改过的那一张。

JavaScript 老大盯着越画越大的白幕：“我只是在整理房间，怎么还修起路了？”

## 别堵施工轨道

入口处，HTML 解析器举着扳手赶来。

“哪位把这支队伍塞进了普通 `<script>`？”

门上的工作牌还写着：

```html
<script src="./main.js"></script>
```

里面却全是 `import`。

加载员换了块牌子：

```html
<script type="module" src="./main.js"></script>
```

“入口按模块解析，才能使用这些静态导入导出。”

HTML 解析器看着队伍，手已经摸到罢工牌：“这么多人，我得停到什么时候？”

加载员把队伍领到旁边的准备区。

“这张写在 HTML 里的模块入口没带 `async`。模块和依赖加载时，继续解析 HTML；等文档解析完成、模块图也准备好，再按规则安排执行。默认就有延迟执行的行为，不用再加 `defer`。”

HTML 解析器放下罢工牌，继续搭 DOM。

脚本 `async` 骑着摩托从旁边驶过：“挂上我的牌子，模块图准备好就能执行，不必等 HTML 全部解析完！”

HTML 解析器把刚放下的牌子又拿了起来。

加载员赶紧拦住摩托：“这次不用。”

远处，一只模块抱着文件冲关，却被浏览器海关拦住。服务器回来的包裹上，竟贴着 `text/html`。

HTTP 拆开一看，是一张错误页面。

“扩展名叫 `.js`，不代表里面一定是 JavaScript。”

海关把规则贴在门边：“模块脚本要通过严格的 MIME 类型检查；跨源加载还得满足 CORS。不能因为认识 `import`，就跳过检查。”

加载员把测试入口也改成 HTTP 地址：“本地试这些例子，起个开发服务器。别双击 HTML，用 `file://` 来考验通行规则。”

## 又请了一遍，为什么没动？

模块图终于备齐。

在这张没有循环、也没有顶层 `await` 的图里，依赖先执行，使用依赖的模块随后接班。先从哪条分支走，由导入关系和声明顺序决定，不由下载速度抽签。

`logger.js` 完成初始化，刚坐下，库存模块又拍了拍窗口。

“我也导入了。再初始化一次。”

日志模块把椅子往后挪了半寸：“刚做过。”

“那是订单模块请的。”

“请的是同一个。”

加载员翻开登记册，指着同一条记录。

“在同一个文档的模块环境中，同一个模块身份会复用已有记录。这里都是 JavaScript 模块，导入解析到同一个 URL，就不会因为多了一位使用者，重新执行一遍顶层代码。”

JavaScript 老大不信，拿来一份更小的试验：

```javascript
// counter.js，独立的小实验
console.log("计数器上岗");

export let count = 0;

export function increment() {
    count += 1;
}
```

订单模块和库存模块同时申请 `./counter.js`。

白幕只亮了一次：

```text
计数器上岗
```

HTTP 从缓存仓库探出头：“又是我的功劳？”

加载员把两本账分开：“HTTP 缓存决定响应能不能复用。模块登记册记的是这一轮环境里的模块记录和求值状态。就算刷新后脚本从 HTTP 缓存取回，新文档里的模块也照样要执行。”

Web Worker 戴着毛线帽探头：“我的分部也有一份呢？”

“那是另一套环境，别拿主页面的上岗记录报销。”

JavaScript 老大又偷偷给地址加了参数：`./counter.js?v=2`。

门口立刻出现第二只计数器。

加载员扶住额头：“URL 变了，可以形成另一个模块身份。登记册还区分模块类型。别把‘同一个模块执行一次’念成‘同名文件在整个浏览器永远只执行一次’。”

第二只计数器把空白账本翻开。

第一页也是零。

## 窗口里怎么还会变？

JavaScript 老大把参数擦掉，继续用原来的计数器。

```javascript
// main.js，接上面的独立小实验
import { count, increment } from "./counter.js";

console.log(count); // 0
increment();
console.log(count); // 1
```

“奇怪。”JavaScript 老大捏着导入单，“刚领出来不是零吗？谁偷偷把我这份改了？”

管房间的小弟把导入窗口转了半圈，露出后面连着计数器房间的细线。

“没领副本。`import` 接过来的是活绑定，读的是导出方当前的绑定值。计数器把 `count` 加到一，窗口里自然看到一。”

JavaScript 老大拿笔伸进窗口，想直接写 `count = 100`。

窗口“啪”地合上。

“导入方不能给这个导入绑定重新赋值。”

“能看，不能改？”

“不能直接换这个绑定。如果导出的是对象，对象本身也没被冻结，属性仍可能修改。窗口可不负责把里面的东西全部冻住。”

JavaScript 老大只好把笔交还给 `increment()`。

库存模块在旁边点头：“同一个计数器，同一套状态。不是每人抱回一只私人副本。”

## 两个都喊先等一下

下午，订单模块想在处理后更新面板，面板模块又想读取订单总数。

两条线在白幕上绕成一个圈。

加载员没有再多叫一份订单模块，只把线接回已有节点。

JavaScript 老大松了口气：“圈也能接？那就继续。”

事故演练台放上两份缩小后的代码：

```javascript
// a.js，作为这次演练的入口
import { b } from "./b.js";
export const a = b + 1;
```

```javascript
// b.js
import { a } from "./a.js";
export const b = a + 1;
```

`a.js` 指着右边：“先有 `b`，我才能算。”

`b.js` 指着左边：“先有 `a`，我才能算。”

JavaScript 老大搬来两把椅子：“那就坐着等。”

椅子还没落地，警报已经响了。

```text
ReferenceError: Cannot access 'a' before initialization
```

“不是说能接吗？”

“能接好绑定，不代表值已经初始化。”加载员指着空窗口，“从 `a.js` 进入这张图，求值走到 `b.js` 时，`a` 的 `const` 初始化还没发生。现在就读，撞上暂时性死区，直接报错，不会乖乖排队等出一个答案。”

JavaScript 老大把两把椅子踢回墙边。

“那见到循环就拆？”

“循环依赖本身合法。有些循环能正常工作，关键是读取发生在什么时候。”

加载员换上另一组代码：

```javascript
// a.js，仍作为入口
import { readA } from "./b.js";

export const a = 1;
console.log(readA()); // 1
```

```javascript
// b.js
import { a } from "./a.js";

export function readA() {
    return a;
}
```

这次 `b.js` 先准备函数，没有立刻读取 `a`。轮到 `a.js`，`a` 初始化成一，再调用 `readA()`，窗口里已经有了值。

警报没响。

“看见没有？函数里写着一个名字，不等于定义函数时就读它。”

JavaScript 老大点点头，又看向业务里的那团线。

订单模块要面板，面板要订单，统计模块还在中间挥手。

“能跑是一回事，这团线明天谁修？”

最后，公共计数搬进独立的状态模块，订单与面板各自导入。需要更新面板时，由入口统一协调。

白幕上的圈终于解开。

## 请了个会睡觉的亲戚

线路刚理顺，配置模块又在门上挂了一张暂停牌。

```javascript
// config.js
const response = await fetch("/api/config");

if (!response.ok) {
    throw new Error("配置加载失败");
}

export const config = await response.json();
```

日志模块站在外面，订单模块站在日志模块后面，入口站在队伍末尾。

“人都齐了，为什么还不开工？”

配置模块指着网络方向：“配置还没回来。”

JavaScript 老大抓起暂停牌：“`await` 不是要待在 `async` 函数里吗？”

“模块顶层也能用。”加载员把牌子挂回去，“这叫顶层 `await`。配置模块的后续求值暂停，静态依赖它的模块也得等它完成，等待可以沿依赖链传到入口。”

旁边一条不依赖配置的分支照常开工。事件大厅还在领取其他任务，浏览器也没被钉在原地。

“只等有关的人？”

“不会因为这个等待把主线程锁死。但把配置挂在大家都依赖的底层，影响范围就大了。还有，`await` 前后的同步代码照样可能占用主线程。”

JavaScript 老大看向越来越长的队伍：“网络一直不回呢？”

“Promise 一直 pending，这条链就可能一直等；加载或求值失败，也会让依赖它的启动流程失败。超时、错误提示、降级方案，要由应用安排。”

配置模块举着暂停牌，小声说：“我不是故意的。”

“所以更得把你放对地方。”

浏览器老大又收走一张刚写好的验收单。上面写着：“收到 `DOMContentLoaded`，所有模块里的异步初始化都完成。”

“这句不能签。别把 DOM 就绪事件当成所有顶层 `await` 都已完成的通知。需要确认应用启动完毕，就明确等待相应的初始化结果。”

加载员把配置模块移到真正需要这份配置的功能分支，基础消息界面先亮了起来。

## 聚会等点名再开

启动时间还是太长。

队伍尽头，一只报表模块拖着图表工具箱、导出工具箱和一整箱日期处理零件。

JavaScript 老大翻遍首页：“报表按钮都没点，你来干什么？”

报表模块亮出入口签的静态导入单。

“名单上有我。”

“可今天可能根本没人看报表！”

“那也是名单上有我。”

`import` 把手一摊：“让我按名单请人，现在又嫌饭桌太大。”

JavaScript 老大把报表从启动时的静态导入里移走，改成按钮被点击后再发邀请。页面已经有一个 `id="report"` 的按钮，`report.js` 则导出负责打开报表的 `showReport()`：

```javascript
const button = document.querySelector("#report");

button.addEventListener("click", async () => {
    button.disabled = true;

    try {
        const { showReport } = await import("./report.js");
        await showReport();
    } catch (error) {
        console.error("报表加载或打开失败", error);
    } finally {
        button.disabled = false;
    }
});
```

门口安静了。

直到主人点下报表按钮，邀请单才真正发出。

Promise 抱着三盏状态灯的订单箱出现，先亮起等待灯。报表和它需要的依赖备齐，求值成功，订单箱才交出模块命名空间对象；`showReport` 从里面被取出来，走上工作台。

“带括号的 `import()` 是动态导入表达式。”加载员合上名册，“运行到这里才发起导入，返回 Promise。可以放在条件或函数里，也可以按运行时算出的路径选择模块。”

JavaScript 老大指着空下来的启动通道：“这回终于只请需要的。”

“前提是别的启动模块没又把报表静态导入。”加载员沿白幕检查一圈，“动态写在这里，不会抹掉别处已经存在的依赖。”

主人第二次点开报表。

`showReport()` 又工作了一次，报表模块的顶层初始化却没有重来。

“动态导入也认同一份模块记录。重复调用不会自动重置状态。”

Web Worker 拎着保温杯路过，看见报表开始算一大批数据，主动让开门。

JavaScript 老大却拽住毛线帽：“都动态加载了，怎么还是我算？”

“`import()` 决定什么时候加载，没替你申请新线程。”Web Worker 扶正帽子，“重计算要搬到分部，得另办手续。”

## 人齐了，也得站对地方

晚上，消息处理器终于从咖啡机下面抽了出来。

订单有订单的房间，库存有库存的窗口；共用的日志只上岗一次，需要互通的状态接着活绑定；报表工具箱等按钮点名，才从远处运来。

加载员收起那卷名册，卷到最后，还有几条线露在外面。

JavaScript 老大瞥了一眼：“拆完以后，文件确实多了。”

“关系本来就在那里。”加载员把最后一条线收好，“以前全挤在一个文件里，看不见。”

`import` 领着订单模块重新敲门。

“现在能进了吗？”

JavaScript 老大先看工作单，再看后面的队伍。

“能。谁必须现在来，谁等会儿来，先写清楚。”

报表模块隔着隧道喊：“那晚饭呢？”

“按需加载！”
