## 选题

### [x] 12.《关不掉的房间》——作用域与闭包

承接《闹心的变量》。函数执行结束后，JavaScript 老大准备清理房间，却发现一个内部函数仍然握着房间的钥匙，里面的变量因此无法离开。

可以讲：

- 词法作用域
- 执行上下文与词法环境
- 作用域链和变量查找
- 闭包是如何形成的
- 闭包中的变量为什么不会被回收
- 闭包的常见用途与可能造成的内存问题

故事冲突：内存清理员坚持房间已经过期，内部函数却拿出钥匙，证明自己仍然能访问房间里的变量。

### [x] 13.《JavaScript 老大的叠盘子游戏》——调用栈

JavaScript 老大每执行一个函数，就把它的工作盘压到上一只盘子上。函数执行完成后，最上面的盘子才能被取走。

可以讲：

- 调用栈和栈帧
- 函数调用与返回顺序
- 局部变量保存在哪里
- 同步代码为什么会阻塞
- 递归调用
- 栈溢出与 `Maximum call stack size exceeded`

故事冲突：一个递归函数不断要求加新盘子，却迟迟不肯结束，最后盘子堆到了执行大厅的屋顶。

### [x] 14.《事件大厅的插队者》——Promise 与 async/await

任务队列里的普通任务排了很久，微任务却一次次从旁边的小门提前进入执行大厅，引起双方争执。

可以讲：

- Promise 的 `pending`、`fulfilled` 和 `rejected`
- Promise 状态为什么不可逆
- `.then()`、`.catch()` 和 `.finally()`
- Promise 链与值的传递
- 微任务队列
- `async` 函数的返回值
- `await` 如何暂停并拆分函数后续代码
- 微任务过多为什么也会阻塞页面

故事冲突：普通任务认为微任务一直插队不公平，JavaScript 老大只能拿出事件循环的工作制度作出解释。

### [ ] 15.《HTML 解析器罢工了》——DOM 的诞生

HTML 解析器一边阅读文档，一边搭建 DOM。工程进行到一半时，它遇到了一个普通 `<script>`，不得不停下所有工作等待 JavaScript。

可以讲：

- HTML 如何被解析为 token
- DOM 树的建立过程
- 浏览器的容错解析
- 普通脚本为什么会阻塞 HTML 解析
- `async` 与 `defer` 的区别
- CSS、JavaScript 与 DOM 解析之间的关系
- `DOMContentLoaded` 在什么时候触发

故事冲突：HTML 解析器抱怨 JavaScript 总让自己停工，JavaScript 则表示脚本可能会修改尚未建好的 DOM。

### [ ] 16.《像素工地返工记》——重排、重绘与合成

页面刚刚建好，JavaScript 就连续修改元素尺寸。布局工人反复测量，绘制工人不断返工，最终集体要求制定施工规范。

可以讲：

- DOM、CSSOM 与渲染树
- 样式计算
- 布局（Layout）
- 绘制（Paint）
- 分层与合成（Composite）
- 重排和重绘的区别
- 读取布局信息后立即修改样式造成的布局抖动
- `requestAnimationFrame`
- `transform`、`opacity` 与合成层

故事冲突：JavaScript 每改一次尺寸就立即询问新位置，布局工人只好重复开工，页面因此开始卡顿。

### [ ] 《URL 第一次出门问路》——DNS

作为《凌晨三点的 URL》的前传。URL 知道服务器的名字，却不知道它住在哪里，只能拿着域名一路问路。

可以讲：

- 域名与 IP 地址
- 浏览器缓存、操作系统缓存和 hosts 文件
- 递归 DNS 解析器
- 根域名服务器、顶级域名服务器和权威 DNS
- 递归查询与迭代查询
- DNS 记录与 CNAME
- TTL 与 DNS 缓存

故事冲突：每一位问路人都只知道下一站，URL 起初以为大家在互相推诿，最后才发现这是完整的解析流程。

### [ ] 《浏览器海关》——同源策略与 CORS

JavaScript 想到另一个域名取数据，虽然服务器愿意交货，浏览器海关仍然拒绝把货物交给它。

可以讲：

- 协议、主机和端口如何组成“源”
- 同源策略保护了什么
- 跨域请求不等于请求没有发出
- 简单请求
- 预检请求与 `OPTIONS`
- `Access-Control-Allow-Origin`
- 携带凭证的跨域请求
- CORS 应该由服务端处理的原因

故事冲突：服务器已经把数据送到边境，JavaScript 看得见却拿不到，只能等待服务器补齐通关文件。

### [ ] 《Cookie 的行李检查》——Cookie 与登录状态

浏览器准备发送请求时，一群 Cookie 都想跟着出门，但行李检查员根据目的地、路径和安全规则，只允许其中一部分上车。

可以讲：

- Cookie 如何保存和随请求发送
- `Domain` 与 `Path`
- `Expires` 与 `Max-Age`
- `Secure`
- `HttpOnly`
- `SameSite`
- Cookie 与 Session 的关系
- CSRF 的基本原理
- Cookie 与 `localStorage`、`sessionStorage` 的区别

故事冲突：一个 Cookie 自称与请求关系密切，却因为目的地不符或缺少安全标记，被检查员拦了下来。

### [ ] 《TCP 老司机遭遇新对手》——HTTP/3 与 QUIC

延续 TCP 与 HTTP/2 系列。TCP 老司机发现新的 HTTP/3 不再乘坐自己的车，而是在 UDP 的地盘上搭建了一套新的运输系统。

可以讲：

- HTTP/2 多路复用仍然存在的问题
- TCP 层的队头阻塞
- QUIC 与 UDP 的关系
- QUIC 如何保证可靠传输
- TLS 1.3 与更快的连接建立
- 独立的 QUIC Stream
- 连接迁移与 Connection ID
- HTTP/2 和 HTTP/3 的关系

故事冲突：TCP 老司机起初认为 UDP 不可靠，随后发现 QUIC 在 UDP 之上重新实现了可靠性，还绕开了自己难以解决的队头阻塞。
